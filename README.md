# BioCheck · 证据约束生成与核验

维护人：潘倩。项目主目录为 zktest 的 `/home/zk_test/zk_projects/BioCheck`，主线为 `main`。

面向给定材料的事实关联生成与细粒度核验，可用于问答、雷达调查稿、告警理由和判断更新说明。先读 [项目说明](docs/项目说明.html)（下载后用浏览器打开）：方法、十二项任务、实验安排、接口归属和验收集中在这一个页面。

## 当前状态

本次建立的是独立维护工程和项目说明。`app/`、`tests/` 以及 `examples/good.json`、`bad.json` 来自所提供的 `drug_qa_reference_prototype.zip`，原样保留为规则教学起点。未实现完整语义核验、真实文本事实提取、课题生成算法或HTTP接入；没有启动服务或调用付费模型。

原型使用虚构材料。其 `PASS` 只表示限定规则通过，不能作为医学事实正确或发布许可。当前主要限制包括：直接相信上游结构字段，没有回读原文；一句中任一数值匹配可能漏掉其他错数；数字格式覆盖有限；现有测试不能证明六类错误分别检出。

原型只完成有限规则与模板演示，不是 RefChecker、MedScore 等论文作者实现。复用论文方法时须注明出处与实际改动。

## 运行原型

需要 Python 3.10 或以上，当前原型没有第三方依赖、API密钥或网络要求。

```bash
cd /home/zk_test/zk_projects/BioCheck
python3 -m app.cli examples/good.json
python3 -m app.cli examples/bad.json
python3 -m unittest discover -s tests -v
```

模板生成示例可使用 `python3 -m app.cli examples/good.json --generate`。运行输出属于教学结果，不是论文实验成绩。后续命令只有在实现并验证后才能加入这里。
